# How to Add Your Astrologer Photo

1. Save your astrologer photo in this folder
2. Name it: `acharya-anuj.jpg` (or `.png`)
3. Update the config in `index.html`:

```javascript
window.acharyaConfig = {
  phone: "+918218433649",
  whatsapp: "918218433649",
  acharyaImage: "images/acharya-anuj.jpg"  // Change this path
};
```

4. Refresh your browser - the new photo will appear in the hero section with astrological theme decorations!

**Recommended Image Specs:**
- Size: At least 800x1000 pixels
- Format: JPG or PNG
- Aspect Ratio: Portrait (vertical)
- Quality: High resolution professional photo

The image will be displayed with:
- Golden zodiac overlays
- Kundali circle patterns
- Astrological symbol decorations
- Gradient lighting effects
